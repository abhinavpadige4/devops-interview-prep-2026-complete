# Day 3: Docker Basics

## Topics Covered
- Docker architecture and components
- Images vs Containers
- Dockerfile basics and best practices
- Container lifecycle management
- Basic Docker commands (run, ps, stop, rm, images, pull, push)
- Volume management
- Network basics in Docker
- Docker Hub and image repositories
- Multi-stage builds

## Key Concepts
- Client-server architecture (Docker daemon, CLI, REST API)
- Image layers and union file system
- Container isolation (namespaces, cgroups)
- Read-only image layers vs writable container layer
- Docker registry and image tags
- Entrypoint vs CMD
- Environment variables in containers
- Health checks and restart policies

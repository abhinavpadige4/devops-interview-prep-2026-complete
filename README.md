# DevOps Engineer Interview Preparation - 15 Day Plan

This repository contains a comprehensive 15-day study plan for DevOps engineer interview preparation, including hands-on exercises with solutions for each day.

## 📅 Study Schedule

| Day | Topic | Focus Area |
|-----|-------|------------|
| Day 1 | Linux Fundamentals | Users, permissions, file system, basic commands |
| Day 2 | Networking Fundamentals | TCP/IP, DNS, HTTP, network tools |
| Day 3 | Docker Basics | Containers, images, Dockerfile basics |
| Day 4 | Docker Advanced & Networking | Docker-compose, networking, volumes |
| Day 5 | Kubernetes Basics | Pods, deployments, services |
| Day 6 | Kubernetes Networking & Services | Ingress, load balancing, network policies |
| Day 7 | Kubernetes Deployments & Helm | Advanced K8s concepts, Helm charts |
| Day 8 | CI/CD with Jenkins | Jenkinsfile, pipelines, integrations |
| Day 9 | CI/CD with GitHub Actions | Workflows, actions, CI/CD best practices |
| Day 10 | Terraform Basics | Providers, resources, state management |
| Day 11 | Terraform Advanced & Modules | Modules, workspaces, advanced features |
| Day 12 | AWS Core Services | EC2, S3, IAM, VPC, RDS |
| Day 13 | Monitoring with Prometheus & Grafana | Metrics collection, alerting, dashboards |
| Day 14 | Mock Interview | Practice questions and feedback |
| Day 15 | Revision & Gap Filling | Review weak areas, final preparation |

## 🚀 How to Use This Repository

1. **Each day** contains:
   - Topics to study with recommended resources
   - Hands-on exercises to complete
   - Solution scripts/commands for verification
   - Notes.md for personal notes

2. **Exercise Solutions**: All exercise solutions are pushed to GitHub under the respective day's `solutions/` directory

3. **Progress Tracking**: Complete each day's exercises and verify against the provided solutions

## 💡 Tips for Success

1. **Consistency**: Dedicate 2-3 hours daily for study and practice
2. **Hands-on Practice**: Focus on completing all exercises, not just reading
3. **Documentation**: Keep notes in each day's notes.md file
4. **Verification**: Always check your solutions against the provided ones
5. **Community**: Engage with DevOps communities for doubt clarification
6. **Mock Interview**: Treat Day 14 seriously - simulate real interview conditions

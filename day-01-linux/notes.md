# Day 1: Linux Fundamentals

## Topics Covered
- Linux file system hierarchy
- User and group management
- File permissions and ownership
- Essential Linux commands (ls, cd, cp, mv, rm, find, grep, etc.)
- Process management (ps, top, kill, nice, renice)
- Text processing (sed, awk, cut, sort, uniq)
- Basic networking commands (ifconfig, ip, ping, netstat, ss)
- Package management (apt, yum, dnf)
- Systemd and service management
- Shell scripting basics

## Key Concepts
- `/etc/passwd` vs `/etc/shadow` vs `/etc/group`
- Permission bits (rwx) and octal notation
- Special permissions (SUID, SGID, sticky bit)
- Process states and signals
- Environment variables and shell variables
- Redirection and piping
- Mount points and filesystems

## Common Interview Questions
1. How do you check disk usage and available space?
2. Explain the difference between `su` and `sudo` commands.
3. How would you find all files modified in the last 24 hours?
4. What is the difference between hard links and soft links?
5. How do you check running processes and kill a process?
6. Explain the Linux boot process.
7. What are inodes and how do they work?
8. How do you troubleshoot a system that won't boot?
9. What is the difference between `ps aux` and `ps -ef`?
10. How do you schedule tasks in Linux?

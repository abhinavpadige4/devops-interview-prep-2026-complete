# Day 4: Docker Advanced & Networking

## Topics Covered
- Docker Compose for multi-container applications
- Advanced networking (overlay, macvlan, none drivers)
- Service discovery and load balancing in Docker
- Docker Swarm basics
- Stack deployment and service scaling
- Health checks and restart policies
- Secrets and configs management
- Resource constraints (CPU, memory limits)
- Logging drivers and monitoring
- Private registry usage

## Key Concepts
- docker-compose.yml version 3 syntax
- Service definition and dependencies
- Volume sharing between services
- Network aliases and service discovery
- Rolling updates and rollbacks
- Service modes: replicated vs global
- Placement constraints and preferences
- Configs vs Secrets vs environment variables
- Healthcheck intervals and retries
- Resource reservations vs limits

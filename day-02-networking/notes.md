# Day 2: Networking Fundamentals

## Topics Covered
- OSI and TCP/IP network models
- IP addressing (IPv4 and IPv6)
- Subnetting and CIDR notation
- DNS resolution and name services
- HTTP/HTTPS protocols
- Common network tools (ping, traceroute, netstat, ss, tcpdump, Wireshark)
- Port scanning and network services
- Firewall concepts (iptables, firewalld, ufw)
- Load balancing and proxy concepts
- Network troubleshooting methodology

## Key Concepts
- IP address classes and special addresses
- Subnet masks and network vs host portions
- Default gateways and routing tables
- ARP (Address Resolution Protocol)
- DHCP (Dynamic Host Configuration Protocol)
- NAT (Network Address Translation)
- TCP vs UDP protocols
- Well-known ports (0-1023)
- Three-way handshake and connection states
- ICMP (Internet Control Message Protocol)

## Common Interview Questions
1. Explain the difference between TCP and UDP protocols.
2. What is the three-way handshake in TCP?
3. How does DNS resolution work?
4. What is the difference between a hub, switch, and router?
5. Explain NAT and when it's used.
6. What is CIDR notation and how do you calculate subnets?
7. How does ARP work and what is its purpose?
8. What are the well-known ports for HTTP, HTTPS, SSH, DNS?
9. Explain the difference between forward and reverse proxy.
10. How would you troubleshoot a network connectivity issue?

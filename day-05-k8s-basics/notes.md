# Day 5: Kubernetes Basics

## Topics Covered
- Kubernetes architecture and components
- Pods, deployments, services, and namespaces
- kubectl command-line tool
- Manifest files (YAML) and declarative management
- Labels and selectors
- Resource requests and limits
- Basic networking in Kubernetes
- Volumes and persistent storage
- ConfigMaps and Secrets

## Key Concepts
- Control plane vs worker nodes
- etcd, API server, scheduler, controller manager
- Pod lifecycle and restart policies
- Deployment strategies (RollingUpdate, Recreate)
- Service types (ClusterIP, NodePort, LoadBalancer, ExternalName)
- Label-based service discovery
- Resource quotas and limit ranges
- Init containers and sidecar patterns
- Health checks (liveness, readiness, startup)

## Common Interview Questions
1. What is Kubernetes and what problem does it solve?
2. Explain the Kubernetes architecture components.
3. What is the difference between a Pod and a Deployment?
4. How do Services enable communication between Pods?
5. What are labels and selectors used for in Kubernetes?
6. How do you manage configuration in Kubernetes?
7. What is the difference between ConfigMap and Secret?
8. How do you scale applications in Kubernetes?
9. What are init containers and when would you use them?
10. How do you troubleshoot a Pod that's not starting?
